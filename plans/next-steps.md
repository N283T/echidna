## 3. ブランディング: アイコン作成

**名前の由来**:
- ギリシャ神話のEchidna (エキドナ) = 半人半蛇の怪物、**キメラ (Chimera) の母**
- ChimeraXの拡張機能 (children) を生み出すツール → Echidna (母)
- echidna = ハリモグラ (英語名) という偶然の一致も活用

**デザイン案**:
- ハリモグラをベース
- 翼を追加 (ChimeraXの「キメラ」要素)
- 蛇の尻尾 (神話のEchidna要素)
- シルエットベースでシンプル・可愛い

```
     /\  /\
    (  \/  )   <- 翼
   /~~~~~~~~\
  | ・    ・ |  <- ハリモグラの顔
   \  ︶   /
    ~~~~~~~~   <- トゲトゲ
       |
      ~~~      <- 蛇の尻尾
```

**用途**:
- GitHub リポジトリアイコン
- CLI起動時のバナー (ASCII art?)
- ドキュメント
