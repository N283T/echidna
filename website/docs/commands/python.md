# python

Show ChimeraX Python environment information.

## Usage

```bash
echi python [OPTIONS]
```

## Options

| Option | Description |
|--------|-------------|
| `-f, --format <FORMAT>` | Output format: `text` (default) or `json` |

## Examples

```bash
# Text output
echi python

# JSON output
echi python --format json
```
