# docs

Open ChimeraX documentation in your browser.

## Usage

```bash
echi docs [OPTIONS]
```

## Options

| Option | Description |
|--------|-------------|
| `--dev` | Open developer documentation |
| `--api` | Open API reference |
| `-s, --search <QUERY>` | Search query |

## Examples

```bash
# Open main ChimeraX docs
echi docs

# Open developer docs
echi docs --dev

# Open API reference
echi docs --api

# Search for a topic
echi docs --search "volume"
```
